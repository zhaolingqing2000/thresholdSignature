# Binding Guest Feasibility Spike

This directory is reserved for a RISC Zero guest implementation of the
cross-layer binding relation. The current repository does not yet contain a
guest ELF, image ID, or `risc0-build` integration.

The `concrete-binding` feature therefore reports an explicit blocker instead
of falling back to the prototype digest proof. Formal experiments must label
this state as `PARTIAL CONCRETE INSTANTIATION`.
